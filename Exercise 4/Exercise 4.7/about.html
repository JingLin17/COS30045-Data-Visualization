About This Project

This site was built for COS30045 Exercise 0.2 to demonstrate a multi-page website using HTML, CSS and JavaScript, with regular commits to a GitHub repository.

Purpose

A small demonstration website exploring appliance energy consumption in the Australian market, built ahead of later D3.js-based data visualisation exercises.

Technologies used

Semantic HTML5, an external CSS stylesheet, and vanilla JavaScript (no frameworks or libraries) for interactivity.

Generative AI use

Generative AI (Claude) was used to help plan the site structure, draft starter HTML/CSS/JS, and review the code. All code was reviewed and understood before submission.
